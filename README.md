# WL_PT_Challenge_Generator

# Getting Started
1. Sign up for the API to get an API key.
2. Create a file called api_key.txt. In it, type API_KEY=<your_api_key_here>
3. Run the below command to ensure you can execute the script:
```bash
chmod u+x generate_challenge.sh
```
4. Run the following command to get a new WL monthly PT challenge!
```bash
./generate_challenge
```
